# Security policy

This repository contains an offline defensive log-triage prototype.

## Reporting a vulnerability

If you discover a security issue in this project, please avoid sharing secrets, private logs, or exploit details in public issues. Contact the maintainer privately through the repository's GitHub profile or GitHub's private vulnerability reporting feature (if enabled). Include a minimal reproduction with synthetic data.

## Supported versions

Security fixes are currently considered for the latest `main` branch only. This is a best-effort open-source prototype; no guaranteed response or remediation timeline is offered.

## Scope

Do not test third-party systems without authorization. The tool does not send network requests and should be run only against data you are permitted to process.
