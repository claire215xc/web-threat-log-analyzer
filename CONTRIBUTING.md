# Contributing

Thank you for your interest. Contributions that improve parser compatibility, defensive detections, performance, documentation, or automated tests are welcome.

1. Open an issue describing the proposed change.
2. Use synthetic examples or RFC 5737 documentation IP addresses (not proprietary logs).
3. Add or update tests with code changes.
4. Run `python -m unittest discover -s tests -v` before proposing a pull request.
5. Explain false-positive considerations for new detection patterns.

Please do not submit live credentials, customer data, internal network details, or exploit payloads targeting real services.
